第一部分 三维影像——从磁共振原理到数据处理

▶

理解功能磁共振成像的基本原理与适用范围，是设计脑成像实验的第一步。本节覆盖从研究方法决策、实验室预约到数据获取和处理的完整流程。

第一步——MRI技术基本原理与实验准备▶

fMRI的基本原理

fMRI通过测量血氧水平依赖（BOLD）信号间接反映神经活动。当神经元集群发放动作电位时，局部脑血流和耗氧量增加，引起脱氧血红蛋白与氧合血红蛋白比例的改变——脱氧血红蛋白为顺磁性物质，会降低局部MR信号；其浓度的下降导致信号增强。BOLD信号的峰值出现在神经活动后约5–10秒，滞后于真实神经事件约1–2秒。这意味着fMRI测量的是与神经活动耦合的血管响应，而非神经活动本身。

fMRI适用于哪些研究问题

  • 任务态fMRI：定位特定认知功能的脑区（如工作记忆、语言、运动控制）；检验明确预测脑区激活的理论假设；比较不同实验条件下的脑激活差异。
  • 静息态fMRI：识别大尺度脑功能网络；在无法执行任务的群体中使用（婴儿、阿尔茨海默病患者等）；大规模群体神经科学研究。

fMRI不适用于哪些问题

  • 需要因果推断的脑-行为关系问题（fMRI为相关性方法）
  • 毫秒级神经动态过程（EEG/MEG更适合）
  • 单一被试的临床诊断（术前功能定位除外）
  • 无法在扫描仪中有效操作的研究构念
  • 小样本的脑-行为个体差异检测（单变量分析方法通常需要千人级样本量）

主要局限与注意事项

  • 头动伪影在发育、精神疾病和儿童群体中尤为严重
  • BOLD信号的个体内和个体间变异性大
  • 分析流程的灵活性大——一项系统性评估测试了768种fMRI分析流程，大多数无法产生一致结果
  • 血压、心率、咖啡因、饮食、昼夜节律等均影响BOLD信号

实验当天流程

  • 前期准备：确认实验方案已通过伦理审查；准备知情同意书；在扫描前完成行为预实验以优化任务设计
  • 被试接待：提前向被试详细说明实验流程和注意事项；确保被试充分理解并签署知情同意书
  • 安全检查（关键步骤）：在进入扫描间之前，逐一确认被试体内无金属植入物（心脏起搏器、动脉瘤夹、金属假牙、骨科内固定物等）；移除所有金属物品（眼镜、发夹、首饰、手表、皮带扣等）；确认被试无纹身（部分纹身颜料含金属成分）
  • 扫描操作：由磁共振实验室的专业技师执行——研究者无需掌握机器操作细节
  • 获取数据：扫描结束后，从技师处获取DICOM格式的原始数据

从第一部分到第二部分
获取和查看MRI数据是一项技术门槛，但它本身并不赋予解剖学理解。制约因素通常并非数据或软件，而是缺乏对脑解剖结构的坚实三维空间认识。下一节正是为了弥补这一缺口。

第二部分 三维脑解剖——建立空间理解

▶

神经影像论文通常以解剖或功能标签指代脑区。阅读这类文献需要的不只是名称识别——更需要理解各结构在三维空间中的相对位置关系。

第一步——脑区如何被定义与标记▶

存在多种脑区分割方案，各自依据不同的原则对大脑进行划分：细胞构筑（Brodmann分区）、大体解剖（脑回与脑沟标志）或功能连接。这些方案之间并不总能对齐——同一解剖位置在不同图谱中可能对应不同的标签。

常用的分割图谱：

  • AAL——116个区域（90个皮层区，26个小脑区），fMRI文献中引用最多
  • Harvard-Oxford——随FSL发布的概率图谱，每个体素携带属于某一结构的概率值
  • Desikan-Killiany——68个皮层区（每半球34个），FreeSurfer的默认输出
  • HCP-MMP 1.0——每半球180个区域，基于人类连接组计划的多模态数据

从第二部分到第三部分
三维图谱构建了空间知识，但知识在被产出检验之前仍停留在抽象层面。当研究者将脑区从数据中分割出来并转化为物理实体时——学习便具有了自我修正的性质。从数字探索到物理制造的转变闭合了一条反馈环路。下一节介绍实现这一转变所需的工具和方法。

第三部分 三维建模与三维打印——从数字模型到物理实体

▶

第一部分生成的数字脑模型，经第二部分获得解剖学理解后，可通过三维打印实现物质化。本节概述三维打印的研究应用，并提供实操工具。

第一步——三维打印的研究应用▶

三维打印已在多个学科的研究中获得应用。以下为经核实的代表性案例：

产前依恋

随机对照试验（n=184）发现，三维打印胎儿模型和三维打印图片均显著提升了父母产前依恋评分，并降低了抑郁和焦虑水平。

Coté et al., 2023, JOGNN

回忆疗法

三维打印的个人物品复制品在回忆疗法中充当了有效的多感官记忆线索，提供了超越照片的提取优势。

Anderson et al., 2024, J. Applied Gerontology

从第三部分到第四部分
三维打印将解剖模型带入物理空间，使其可被触摸和共享。但三维技术同样可以沿相反方向运作：使参与者沉浸在虚拟环境中。虚拟现实将之前各节所论述的逻辑——空间理解、数字建模、实时交互——延伸至实验研究领域。

第四部分 三维空间中的实验——虚拟现实技术入门

▶

虚拟现实（VR）头戴式显示器使研究者能够构建完全受控的三维实验环境。本节从方法论决策出发，提供从环境搭建到实验开发的操作指南。

第一步——研究中为什么需要VR▶

核心优势：实时追踪头部运动、双目视差提供真实深度感知、可构建现实中不存在的场景、安全呈现危险情境。当这些优势超过其局限时，VR是最合适的方法。

主要局限：晕动症；设备重量与佩戴舒适度；空间压缩（感知距离短于真实距离）；无法在fMRI扫描仪中使用。

第二步——从零搭建Unity VR环境▶

以下步骤完成后，你将拥有一个可运行的基础VR场景。

1. 安装Unity：通过Unity Hub安装Unity 2022 LTS或更高版本。 2. 创建项目：选择3D Core模板（不选VR模板）。 3. 配置OpenXR：Edit → Project Settings → XR Plugin Management → 安装并勾选OpenXR → 点击Fix All。 4. 添加控制器配置：在Interaction Profiles中添加对应硬件（HTC Vive / Oculus Touch）。 5. 安装XR Interaction Toolkit：Package Manager → 添加 com.unity.xr.interaction.toolkit → 导入Starter Assets。 6. 创建XR Origin：Hierarchy右键 → XR → XR Origin (Action-based) → 将Starter Assets中的左右手柄预设拖到对应Inspector上。 7. 测试交互：创建Cube → 添加XR Grab Interactable组件 → Play → 手柄靠近按Grip键抓取。

XRI的交互架构由三个角色构成：Interactor（交互发起者——手柄射线和手部碰撞体）、Interactable（被交互物体）、Interaction Manager（统一管理）。

第三步——VR程序开发流程▶

环境搭建完成后，一个完整的VR程序经历四个阶段：

1. 搭建场景——自己建模（Blender等）或利用现成素材（Unity Asset Store、Sketchfab）。先用简单的几何体做白模测试，验证交互逻辑后再替换精细模型。

2. 添加交互——将脚本挂载在物体上，定义手柄操作与物体响应。三种基本模式：射线交互（远距离选择）、抓取交互（近身拿起操控）、碰撞交互（区域触发）。

3. 连接设备——启动硬件和SteamVR → 确保Unity启用OpenXR → 场景中放置XR Origin → 点击Play在头显中实时预览。

4. 打包发布——PC VR生成.exe（也可直接在Unity中运行），一体机生成APK部署。

第七步——VR的主要应用方向▶

空间导航与情景记忆

VR已成为研究人类空间导航的常用方法，实验者可以精确控制每一个地标和空间线索。该方法在网格细胞样表征的发现中起到了重要作用（Doeller et al., 2010, Nature）。

社会认知

VR可系统性操控注视方向、人际距离、面部表情和化身外观，同时严格控制混淆变量。已应用于社交焦虑和内隐社会偏见研究。

暴露疗法

VR暴露疗法是沉浸式技术最成熟的临床应用之一。RCT证据支持其对恐高症、飞行恐惧、PTSD和社交焦虑的疗效。关键优势在于剂量可精确控制。

风险决策

VR可在零风险环境中呈现高度危险情境（火灾逃生、交通事故），用于研究紧急决策过程——这在现实中因伦理原因无法实现。
